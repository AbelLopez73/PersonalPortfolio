# PersonalPortfolio

Personal portfolio website built with Angular on the frontend and ASP.NET Core on the backend.

## Goals

- Showcase professional profile and resume in English.
- Present portfolio projects and blog content.
- Allow visitors to send suggestions through Telegram.
- Deploy on a free hosting setup.

## Stack

- Frontend: Angular
- Backend: ASP.NET Core Web API
- Messaging: Telegram Bot API

## Status

This project is in early setup and backlog definition phase.
